# v0.3.15 主界面冰蓝统一

主界面按参考图完成冰蓝桌面助手复刻，所有主页面统一为同一套深蓝配色，同时保留现有功能和数据流。

- 首页使用左侧导航、对局横幅、本地精选、快捷入口、推荐与历史侧栏、天梯排行和底部状态条的一屏布局。
- 实时对局、卡牌资料、卡组工具、对局记录和设置统一使用深蓝背景、冷蓝面板、冰蓝边框与蓝色交互状态。
- 品牌徽标、卡牌费用、警告、成功和失败等有明确含义的颜色继续保留。
- 地下竞技场重选时，唯一可信的传说团队允许多处画面识别错字；无法唯一确认时不显示或伪造选取率。
- 所有导航、日志监听、记牌、收藏读取、历史记录、卡牌详情和设置功能保持原行为。
