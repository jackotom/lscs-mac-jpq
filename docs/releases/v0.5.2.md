# v0.5.2 克尔苏加德复活数量修复

## 更新

- “天定之灾克尔苏加德”还在牌库时，会直接按本局同侧已死亡的不稳定的骷髅显示复活数量。
- 卡牌亮出后会自动使用游戏日志中的数值校准，0 也会正常显示。
- 我方与对手分开统计；重复日志不会重复增加，新对局不会沿用上一局数量。
- 卡牌正文与“会复活（N）”栏同步更新；暂时无法确认时显示“复活数量未知”，不再出现“复活 个”。

## 版本

- 应用界面、安装包和依赖锁文件统一为 `0.5.2`。

## 验证范围

- 覆盖卡牌仍在牌库时的实时计数、两种不稳定的骷髅编号、重复日志去重和双方隔离。
- 覆盖卡牌亮出后的真实数值校准、已知 0、新对局归零和未知数量文案。
- 覆盖主界面详情、游戏内悬浮详情和独立卡牌预览共用的显示链路。

## 发布验证

- 149 个测试文件通过，共 1214 项通过、1 项按预期跳过；78 项窗口与设置专项检查通过。
- 7 阶段发布验证、Apple 芯片安装包签名和启动检查全部通过。
- 用接近真实对局的重复日志验证：克尔苏加德尚未公开自身计数时，正文显示“复活 2 个”，独立栏显示“会复活（2）”。
- 输出包与已安装应用均为 `0.5.2`，两者程序内容校验值一致。
