# v0.6.3 权限管理与悬浮窗修复

## 用户可见变化

- 二级工作台第一行新增“权限管理”。
- 屏幕录制权限正常时显示“正常”；缺失时显示“点击授权”。
- 未授权时后台不再反复请求录屏权限；主动授权临时失败时可以再次点击重试。
- 对手悬浮窗保留回合和行动方；拉高窗口时只扩展牌表，不再拉伸固定信息行。
- 未进入真实对局、已结束对局或停留在竞技场选牌页时，双方场攻计数器不会出现。

## 权限说明

- 当前只需要屏幕录制权限，用于本机识别炉石模式、套牌和竞技场候选牌。
- 不需要麦克风、相机、辅助功能或完全磁盘访问。
- macOS 中修改录屏权限后，需要彻底退出并重新打开软件。
