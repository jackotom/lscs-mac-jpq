# v0.7.0 全局效果与牌库候选高亮修复

## 用户可见变化

- 记牌器已审查并覆盖去除 `CORE_` 重印后的 65 张长期全局效果卡；本方和对手分开显示。
- 亡语、条件战吼和永久附魔只有在真实生效后才记录；对局结束后的迟到日志不会把旧效果写回。
- 同一张牌回手后再次打出可继续累计，镜像日志不会重复计数。
- 悬停“血色招募者”等明确牌库检索牌时，只高亮牌库中符合类型与费用条件的候选；2 费及以下包含 0 费。
- 未审查卡牌、未知正文和损坏实时数据默认不猜测、不误亮。

## 数据与兼容边界

- 65 张长期效果使用已审查安全清单；未来新卡不会在未验证前自动加入。
- 旧版已支持的整手牌、整牌库结构型提醒继续保留。
- 已审查附魔映射和旧硬编码激活属于明确例外，可在卡库资料暂缺时继续恢复来源卡。

## 安装包要求

- 应用界面、安装包和依赖锁文件版本统一为 `0.7.0`。
- 正式安装包必须使用 Developer ID、Hardened Runtime 和可信时间戳，并通过 Apple 公证、票据装订与发布门禁。
