# v0.4.2 独立悬浮窗与智能计数更新

本版本重点打磨对局悬浮体验：场攻、奥秘和智能计数不再挤在同一窗口，用户可按需要分别打开和关闭。

## 更新内容

- 我方场攻、对手场攻、奥秘预测分别使用独立悬浮窗，智能计数进一步做到每条规则一个小窗。
- 设置页增加四类独立总开关；智能计数支持当前相关规则的单项显示与隐藏。
- 奥秘候选加入真实卡图和名称，采用双列紧凑布局，并根据奥秘槽位与候选数量自动调整窗口高度。
- 奥秘图片加载失败时会尝试备用来源，最终保留稳定占位，不影响候选名称和判断结果。
- 智能计数规则库首批覆盖龙牌进度、对手关键同名牌使用次数、法术次数、不同法术派系、不同随从种族、回合内出牌和指定费用等高可信规则。
- 龙牌规则支持动态门槛、全部种族、排除触发牌自身和晚揭示回填；虚空灵魂等关键牌只统计真实打出，直接召唤不会误计。
- 己方计数器按当前套牌自动激活；对手计数器在确认关键牌实际出现后激活，避免开局堆满无关数字。
- 所有新悬浮窗保持鼠标穿透、不抢焦点，单个窗口关闭不会连带关闭其它窗口。

## 可信边界

- 只显示能由炉石日志可靠确认的进度；死亡、治疗、护甲、弃牌、发现、奥秘触发等尚不具备稳定事件来源的类别暂不猜测。
- 规则区分真实使用、直接召唤、生成和变形，重复日志只计一次，新对局会清空本局进度。

## 版本

- 应用版本、依赖锁文件、界面版本标识和 Mac 安装包统一为 `0.4.2`。
