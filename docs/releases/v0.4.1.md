# v0.4.1 可靠性与竞技场卡牌显示修复

本版本不扩张功能范围，重点修复真实玩家环境中的状态串局、套牌误判、缓存损坏和竞技场附带牌显示问题。

## 修复内容

- 修复 `TIME_009t1`、`TIME_009t2` 这类带小写后缀的卡牌编号无法识别的问题。右侧竞技场记牌器现在正确显示“侏儒光环”4 费和“梅卡托克的光环”5 费，不再显示内部编号和费用问号。
- 两张附带光环会显示现有真实影响值；没有独立选取率时继续显示 `—`，不伪造数据。
- 套牌识别增加证据状态：炉石日志确认、选牌页画面确认、本局卡牌推断。相似套牌仍有多个候选时等待更多证据，不直接装载可能错误的牌库。
- 每次开始监听都会创建新的会话身份。旧日志读取、旧画面识别、旧竞技场评分和延迟到达的牌库结果无法覆盖当前会话。
- 模糊画面识别需要连续两次一致才确认；已有完整三张候选时，后续不完整结果不会让界面退化。
- 卡牌库和竞技场评分缓存使用临时文件、安全替换与单份有效备份。正式缓存损坏或更新中断时会尝试恢复，不再轻易丢失最后有效数据。
- 增加异常退出状态记录，但不保存玩家名、套牌内容、日志正文或账号信息。
- 加强完整日志、逐行日志、随机分块、重复事件和长日志回放覆盖，减少日志顺序变化造成的状态不一致。

## 用户可见变化

- 右侧竞技场牌表不再把已知附带牌显示成英文内部编号。
- 套牌状态文案更清楚：能看出是炉石确认、画面找到、本局匹配，还是仍有多个候选。
- 重启炉石、切换日志会话、断网或缓存更新失败时，旧状态污染和有效数据消失的概率更低。

## 版本

- 应用版本、依赖锁文件、界面版本标识和 Mac 安装包统一为 `0.4.1`。
