# v0.6.7 新卡中文卡牌库补全

## 用户可见变化

- 国服官网刚上线的新卡会自动补齐卡牌编号、费用、类型、种族、机制、关联牌和图片，不再因为本地旧卡库缺失而只显示编号。
- 国服官网提供的中文名称与正文继续优先；补充资料不会覆盖已有中文信息。
- 竞技场与普通对局共用补全后的卡牌资料，新卡和衍生牌能更早显示完整中文信息。

## 稳定性

- 全量补充库使用双镜像、独立缓存和严格完整性校验；来源异常时继续使用最后一次有效缓存。
- 同时发生的卡牌库加载会合并，强制刷新会按顺序执行，避免重复下载和缓存覆盖。
- 网络请求有总时限与单镜像时限，不会无限阻塞启动。

## 安装包说明

- 安装包使用钥匙串中的 Developer ID 证书签名，启用 Hardened Runtime 并带可信时间戳。
- 本版本通过 Apple 公证并装订票据后发布。
