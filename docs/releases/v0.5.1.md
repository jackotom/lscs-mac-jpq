# v0.5.1 奥秘窗口交互修复

## 更新

- 修复奥秘助手问号点击后无法收起、收起后无法重新展开的问题。
- 奥秘助手标题栏和问号都可以拖动；移动超过 4 像素时只移动，不会误触收起或展开。
- 收起后整个 44×44 入口都能点击和拖动，问号外观仍保持原大小。
- 修复拖动后收起或展开会跳位置的问题；移动位置和收起状态会在刷新、重启后保留。
- 操作结束或异常中断后会恢复鼠标穿透，不会挡住炉石点击。

## 版本

- 应用界面、安装包和依赖锁文件统一为 `0.5.1`。

- 已在正式安装版中用原生鼠标验证：标题最右缘可收起、44×44 入口四角都可展开、展开与收起状态都可拖动，切换尺寸不跳位。
