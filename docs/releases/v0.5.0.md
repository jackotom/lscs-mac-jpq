# v0.5.0 悬浮窗操作更新

## 更新

- 奥秘助手左上角问号现在可以收起整个候选列表，只保留一个紧凑入口；再次点击即可恢复。
- 折叠状态会在对局刷新和应用重启后保留。
- 我方与对手场攻圆钮可以分别拖动，松手后保存位置，刷新和重启不会弹回。
- 圆钮会根据当前炉石屏幕恢复相对位置，并在屏幕边缘保留安全距离。
- 只有问号和场攻圆钮在操作时接收鼠标，其余透明区域继续穿透，不阻挡炉石点击。
- 修复奥秘助手重新展开后窗口高度被压扁、候选列表显示不完整的问题。

## 版本

- 应用内版本、安装包版本和依赖锁文件统一为 `0.5.0`。
