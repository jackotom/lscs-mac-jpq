# v0.5.4 首次启动自动连接修复

## 更新

- 修复先打开记牌器、后启动炉石时，首次可能一直识别不到牌库的问题。
- 启动时即使只发现基础 `Player.log`，后台仍会继续检查新的游戏日志。
- 炉石生成 `Power.log` 后自动连接并恢复牌库识别，不需要退出重开记牌器。

- 应用界面、安装包和依赖锁文件统一为 `0.5.4`。

- 覆盖现有日志发现、牌库监听和构建检查。
