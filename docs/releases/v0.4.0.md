# v0.4.0 白色主界面与二级工作台

本版本是一次重大更新，重新整理主界面、二级页面、悬浮窗和数据展示，并集中修复窗口稳定性与浅色显示问题。

- 主界面升级为白色首页，各功能页统一进入独立的二级工作台，信息层级更清楚。
- 悬浮窗支持独立的浅色与深色外观，不再被主界面主题绑定。
- 修复窗口错误隐藏、恢复后跑位和多窗口位置互相干扰的问题，窗口显示与位置保存更稳定。
- 首页加入中文图文资讯，并使用 Firestone 的可信统计展示当前环境数据。
- 加强竞技场传说团队长牌名识别，减少长牌名被截断或识别失败造成的统计缺失。
- 修复浅色模式下卡牌详情出现大块黑色区域的问题，卡图与文字恢复正常显示。

## 验证

- 应用版本清单与依赖锁文件已统一为 `0.4.0`。
- 发布说明已核对覆盖本版本全部重大更新。
