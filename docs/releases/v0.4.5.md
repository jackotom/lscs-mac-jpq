# v0.4.5 对局结束牌表保留修正

## 修复

- 对局结束后保留当前构筑或竞技场套牌，不再显示空牌库。
- 清空手牌、场上、墓地、移除区、对手记录和本局计数，下一局从完整牌表重新开始。
- 临时的“等待精确识别”占位牌库不会错误保留到下一局。
- 日志失效、退出模式或确认换套牌时仍会清空旧牌表，避免跨模式串牌。
