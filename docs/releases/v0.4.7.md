# v0.4.7 全局可拖动顶部任务栏

## 更新

- 新增独立的全局顶部任务栏，首页、设置和其它工作台页面共用同一条，不再重复叠加。
- 左侧独立保留 macOS 红黄绿系统按钮区域，中央大面积空白区可直接拖动窗口。
- 右侧最小化、进入工作台和返回首页按钮保持独立点击，不会被拖动区拦截。
- 首页品牌和服务状态单独放在任务栏下方，窗口控制与产品信息分层显示。

## 版本

- 应用内版本、安装包版本和依赖锁文件统一为 `0.4.7`。

## 验证

- 完整自动测试：`143` 个测试文件通过，`1173` 项通过，`1` 项跳过；窗口专项 `76` 项通过。
- 类型检查、正式构建、代表性日志回放、窗口截图、开发签名、Apple 芯片架构和压缩包校验通过。
- 已覆盖到 `/Applications/炉石记牌器.app`，安装后版本、签名和程序内容与验收包一致。
- 从正式安装位置启动后，首页、实时对局和悬浮窗设置均只有一条顶部任务栏；激活与未激活窗口都能从空白区真实拖动。
- 最小化、进入工作台、切换设置和返回首页均已实际点击，按钮不会带动窗口。
