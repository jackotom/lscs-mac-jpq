# v0.4.3 奥秘预测小窗打磨

## 更新内容

- 奥秘预测窗按参考图重做为紧凑单列布局。
- 左上增加外凸问号徽章，标题改为“奥秘助手”。
- 每个候选使用 17px 高横向卡图牌条，左侧显示费用，卡名直接叠在图片上。
- 费用栏按卡牌稀有度显示对应颜色；真实卡图失败时仍保留明确占位。
- 窗口随候选数量自动调整高度，继续保持点击穿透和不抢炉石焦点。

## 验证

- 全量自动测试通过。
- 真实 Electron 小窗验证卡图加载、窗口尺寸、单列布局、无溢出和无焦点抢占。

## 版本规则

- 每次替换 `/Applications/炉石记牌器.app` 前，应用版本必须递增一个补丁号，例如 `0.4.2` 更新为 `0.4.3`。
