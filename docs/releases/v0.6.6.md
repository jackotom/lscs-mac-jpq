# v0.6.6 悬浮窗与竞技场识别修复

## 用户可见变化

- 切换到其它软件再回到炉石、切换桌面空间或开始下一局时，我方和对手悬浮窗会重新确认显示与置顶状态。
- 传说团队的长卡名支持分段识别；“灭世者死亡之翼”和“伊瑟拉，翡翠守护巨龙”会匹配到正确卡牌与统计。
- 竞技场新卡即使尚未进入本地卡库，只要炉石日志带有中文名，牌表就显示中文名；`CAP_407` 现显示为“通缉海报”。

## 稳定性

- 自动恢复悬浮窗不会抢走炉石焦点，也不会在稳定状态持续重排窗口。
- 正式应用与隔离验收使用各自正确的 macOS 跨桌面策略。
- OCR 分段只在同一槽、同一行且片段相邻时合并；传说团队的宽松匹配在核心选定后立即退出，普通选牌保持原容错范围。

## 安装包说明

- 安装包使用钥匙串中的 Developer ID 证书签名，启用 Hardened Runtime 并带可信时间戳。
- 本版本按发布选择未装订 Apple 公证票据，不标记为公证发行版。
