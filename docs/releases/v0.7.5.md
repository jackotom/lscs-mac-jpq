# v0.7.5 战绩与浮窗恢复修复

- 休闲局单独保存、展示和统计，不再按收藏套牌格式归入标准或狂野；已有历史记录不做推测性迁移。
- 对手记牌窗保存折叠状态和展开尺寸，重启后恢复；兼容旧版位置文件，快速折叠与展开按最后选择生效。
- 移除尚未生效的游戏语言、窗口匹配方式、新版本提醒和活动公告控件，保留旧设置文件兼容性。
- 源码开发启动先编译原生组件和主进程，避免加载缺失或过期文件。
- 官网版本和下载同步更新，保留原有界面。

## 下载与安装

下载 Apple 芯片 Mac 安装包与对应 SHA-256 校验文件。解压后把“炉石记牌器”拖到“应用程序”覆盖旧版；本机对局记录和设置继续保留。
