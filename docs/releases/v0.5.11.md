# v0.5.11 对手手牌、竞技场档案与收藏中心

## 用户可见变化

- 对手悬浮窗新增手牌抽取回合、已知卡牌、创建、锻造和增益状态。时间不可靠时只显示回合，不显示虚假倒计时。
- 新增竞技场中心：自动建档、持续更新最终牌组、胜负、奖励、套牌评分、个人统计、本机高胜档案和可信留牌统计。
- 新增收藏中心：已记录卡牌、缺卡、开包历史、分系列保底、卡背、英雄皮肤和硬币。
- 竞技场支持 JSON 导入导出；收藏支持结构化 JSON 和 CSV 导入，也可本机录入开包与装饰品。
- 外部保底结论不直接采用，只根据已确认开包重算，并标明“从本次记录起”。

## 数据边界

- 炉石日志无法完整证明留牌过程时不生成留牌样本。
- 手动开包明确标记为本机录入，不冒充日志数据。
- 长期档案损坏不会阻止实时记牌，辅助悬浮窗不能修改竞技场或收藏数据。

## 版本一致性

- 应用界面、安装包和依赖锁文件版本统一为 `0.5.11`。
