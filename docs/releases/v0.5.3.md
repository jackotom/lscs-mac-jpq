# v0.5.3 悬浮计数器交互修复

## 更新

- 智能计数圆片可以直接抓取拖动；每个计数器只移动自己，并独立保存位置。
- 我方与对手场攻补齐首次移入唤醒，不需要先触发一次额外悬停。
- 拖动超过 `4px` 才移动；短按、松手、取消或抓取丢失后都会恢复鼠标穿透。
- 穿透恢复失败会持续重试，鼠标快速重新移入不会被旧重试再次关闭交互。
- 定时刷新、隐藏再显示、重启和显示器变化不会把已移动的计数器拉回默认位置。
- 默认计数器不再压住场攻按钮或相邻计数器；小屏、负坐标副屏和带 Dock 的工作区会自动换行。

## 版本

- 应用界面、安装包和依赖锁文件统一为 `0.5.3`。

## 验证范围

- 覆盖多个智能计数器的来源隔离、独立位置保存、刷新防回弹和异常关闭清理。
- 覆盖短按阈值、首次移入、松手、取消、抓取丢失、重复离开、快速重新移入和连续失败重试。
- 覆盖 `640×480` 到常见桌面尺寸、31 个计数器、左右 Dock、负坐标副屏和旧版位置文件升级。

## 发布验证

- 全量 `150` 个测试文件通过：`1263` 项通过，`1` 项按预期跳过；额外窗口与设置专项 `90` 项通过。
- 七阶段正式发布检查通过，包含构建、签名、ARM64 打包、日志回放、窗口截图和最终安装包启动。
- 最终安装包的智能计数器专用启动场景通过：窗口为 `60×62`，路由、画面、控制能力和错误日志均正常。
- 安装版用原生鼠标验证：智能圆片、我方场攻、对手场攻均可拖动，短按不会误移动；智能圆片与我方场攻重启后恢复位置，双方场攻位置分别保存。
- `/Applications/炉石记牌器.app` 已替换为 `0.5.3`，安装版与打包成品内容一致，签名与 ARM64 架构检查通过。
