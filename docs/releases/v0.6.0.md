# v0.6.0 Apple 公证发行版

## 用户可见变化

- 对手悬浮窗新增手牌抽取回合、已知卡牌、创建、锻造和增益状态。
- 新增竞技场中心：自动建档、牌组、胜负、奖励、评分、个人统计和导入导出。
- 新增收藏中心：已记录卡牌、缺卡、开包历史、分系列保底和装饰品。
- 修复关联牌池、米尔牢斯全局效果和拖动悬浮窗时其它窗口消失的问题。
- 竞技场胜负按对局标识持久去重，重启后重放同一局日志不会重复累计。

## macOS 发行

- 使用 Developer ID 正式签名。
- 启用 Hardened Runtime 和可信时间戳。
- 通过 Apple 公证服务，并把公证票据装订到应用内。

## 版本一致性

- 应用界面、安装包和依赖锁文件版本统一为 `0.6.0`。
