# v0.7.1 牌库配合高亮

## 用户可见变化

- 悬停、点击或键盘选中当前卡牌和“影响全局”卡时，只高亮牌库中的可靠配合牌。
- 支持类型、费用、攻击、生命、种族、法术派系、关键词和稀有度，并可从配合牌反向找到来源牌。
- 对手窗保持纯预览；手牌、场上、墓地和其它分组不会被当成高亮目标。
- 选中来源为蓝色，配合目标为琥珀色；深浅色、读屏和 100px 窄窗已适配。

## 数据边界

- 真实本机卡库共审计 8139 张可收藏牌，当前 785 张能生成 793 条可靠关系。
- 未完整识别的动态条件、负面构筑条件、随机生成、对手或双方牌库默认不推断。
- 同卡的 `CORE_` / `VAN_` 重印不会互相高亮。

## 验证

- 专项测试、全量测试、正式构建、真实卡库审计和 100×200 Electron 窄窗验收均通过。
- 正式安装包仍需完成签名、公证、票据装订和发布检查。
