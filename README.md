# 炉石 Mac 记牌器

一个本机运行的 Mac 桌面记牌器原型。它只读取炉石日志文件，不读取游戏内存，不注入游戏进程。

当前版本已经包含桌面窗口、自动启动日志监听、炉石重开后的新日志自动切换、收藏套牌自动同步、当前已选套牌直接识别、对局自动匹配卡组、竞技场选牌识别与评分、竞技场牌库自动生成、卡牌缩略图与详细效果、我方牌库统计、事件流、对手已出牌记录和置顶小窗。

已完成的对局会在本机保存最近 100 局，主窗口可查看胜、负、平、总胜率、模式、套牌和结束时间。只有日志能确认本地玩家结果时才记录，数据不会上传。

进入标准或狂野模式时，应用会自动读取本机国服炉石版本，并在左侧显示同版本的国服高胜率卡组推荐，提供胜率、统计场次和卡组代码复制。没有可信国服统计入口、数据过期或版本不一致时会明确说明原因，不会用外服或旧版本数据替代。

## 运行

```bash
npm install
npm run dev
```

每次 Mac 发布都会覆盖固定位置 `outputs/炉石记牌器.app`，同时更新 `outputs/炉石记牌器-mac-arm64.zip`。

只看界面可运行：

```bash
npm run build
npx vite preview --host 127.0.0.1 --port 4173
```

## 日志

优先读取 `/Applications/Hearthstone/Logs` 下最新会话目录。也可以在应用内手动选择日志目录或日志文件。

第一次使用前点“修复日志”，然后完全重启炉石。应用启动时也会自动检查并补全 Power、Zone、Decks、Arena 日志配置，修改前会保留备份。记牌器打开后会自动开始监听；炉石重开并创建新日志目录时会自动跟随。对局开始时优先读取炉石记录的已选套牌，无法直接确认时再根据抽牌和出牌自动匹配；竞技场会自动累计已选牌，地下竞技场重选后的精确 30 张会由同一会话的牌库日志确认，不需要手动设置牌库。

如果当前日志只能确认部分竞技场牌，置顶小窗会明确显示“已确认 N/30”和待识别数量，不再用假卡凑成完整牌库；精确牌库出现后会自动替换为真实 30 张。

## 卡牌库

卡牌数据库首次使用时从[官方卡牌浏览器](https://hs.blizzard.cn/cards/)导入全量传统对战卡牌，并补齐 HearthstoneJSON 的全量衍生牌，保存在本机应用数据目录；同时保留卡牌编号用于日志匹配。之后先读本地快照，只有官网版本变化或发现衍生牌缺失时才更新，不会每次打开软件都抓取全部卡牌。

牌库、对手出牌和竞技场候选牌会使用本地卡牌资料显示清晰缩略图、法力值、攻击/生命、卡牌文字（包括战吼和技能）以及关联牌；主窗口点击卡牌行可展开详情，置顶小窗鼠标悬停即可弹出卡牌预览。生成牌、升级牌和连续法术会在预览中列出对应名称与文字。图片和文字随卡牌数据库一起缓存，不会每次打开软件抓取单张卡牌。

普通对局会等到 `CREATE_GAME` 后，根据本地玩家实际抽到或打出的牌，在收藏套牌中自动选出最匹配的一套；对手抽牌、收藏浏览和对局外日志不会触发套牌匹配。

竞技场评分使用版本化本地缓存。目前数据库保留 HearthArena 专家评分和 Firestone 公开统计：每张牌保存原始评分、卡组胜率、出牌胜率和样本量；低于 2000 个样本会明确标注“样本偏少”。首次使用或评分版本变化时更新，平时直接读取本机缓存，不会每次打开软件都抓取网页。候选牌会按评分显示“顶级 / 优秀 / 良好 / 一般 / 偏弱 / 不推荐”，并自动标出当前三选一的首选牌。竞技场选牌、重选和等待开局时，右侧记牌器只显示 Firestone 风格的“选取率 / 卡牌 / 影响”牌表；进入实际对局后自动恢复普通记牌器。

## 限制

- 真实日志格式可能随游戏版本变化，需要用你的实际日志继续补解析规则。
- 对手职业、手牌数、回合等仍是基于日志事件的近似推断。
